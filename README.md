## Getting Started

```bash
# Clone the repository
git clone https://github.com/Aniket-Solanki/Free-UnsecuredApis-Finder.git
cd Free-UnsecuredApis-Finder

# Install dependencies
npm install

# Start development server
npm run dev
```
